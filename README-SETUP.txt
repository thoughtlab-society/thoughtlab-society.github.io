THOUGHT LAB REDESIGN — PREVIEW PACKAGE

This is a static multi-page website. Keep the existing GitHub repository and publish these files to the same repository to retain the same GitHub Pages URL.

Included: index.html (minimal homepage), separate pages for Blog, Research Decoded, Reviews, Projects, Activities, About; assets/style.css; existing logo and event photos.

CMS note: .pages.yml is a starter configuration for Pages CMS. The editing service must be connected to the GitHub repository and its configuration checked before use. The CMS content collections are a starter structure; this initial website currently presents the preserved page content as static HTML.

Preview locally: open index.html in a browser.

Deployment: upload/replace the site files in the existing repository (thoughtlab-society.github.io) and let GitHub Pages deploy. Do not delete the repository or change its name if keeping the URL is important.
